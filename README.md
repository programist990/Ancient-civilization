# Ancient Civilization — Prototype 0.3

## Запуск на Windows
Открой PowerShell в папке проекта и выполни:

```powershell
.\\venv\\Scripts\\python.exe -m pip install "kivy[base]"
.\\venv\\Scripts\\python.exe main.py
```

Если виртуальное окружение `venv` уже создано и Kivy установлен, достаточно последней команды.

## Управление
- Перетаскивание мышью — перемещение камеры.
- Колесо мыши — приближение и отдаление.
- Нажатие на дерево — добыть дерево (расходуется применение топора).
- Нажатие на камень — добыть камень (расходуется применение кирки).
- Кнопка «Строительство» — открыть отдельную вкладку выбора зданий.
- Выбор дома или магазина — вернуться на карту в режим размещения.
- Нажатие на свободное место — построить выбранное здание.
- Кнопка «Отмена» — отменить размещение.
- Нажатие на построенное здание — посмотреть его назначение.
